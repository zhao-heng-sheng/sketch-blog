# 关于我

> 写代码的人，爱折腾 NAS，爱读杂书。偶尔打打字。

## 我是谁

网名赵恒盛，常用 GitHub [@zhao-heng-sheng](https://github.com/zhao-heng-sheng)。
本职是后端工程师，做过 Vue/React 前端，也搞过一点点 MLOps 和 Chrome 扩展开发。
平时喜欢在 NAS 上瞎折腾，把各种"听起来很酷但其实没什么用"的东西跑起来。

## 这个博客在干嘛

墨与码是我个人的小角落，用来放一些**不太正经**的技术笔记：

- 踩过的坑、翻车现场、复盘
- 折腾过的工具、模型的部署记录
- 偶尔翻到的书、想到的事

**更新频率**：看心情。可能一个月一篇，也可能半年憋不出一篇。
**评论**：暂不开放，但欢迎 [GitHub Issue](https://github.com/zhao-heng-sheng/sketch-blog/issues) 讨论。

## 技术栈

本站用 [VuePress 2](https://v2.vuepress.vuejs.org/) + 自定义手绘主题搭建。
源码在 [zhao-heng-sheng/sketch-blog](https://github.com/zhao-heng-sheng/sketch-blog)，MIT 协议。
字体用了 Google Fonts 上的 **马善政体**（标题）、**站酷快乐体**（强调）、**Noto Sans SC**（正文）。
